# مغامرات الرياضيات – الأستاذة جوادي

مشروع ويب مستقل للعبة رياضيات تفاعلية موجّهة للسنة الأولى ابتدائي في الجزائر.

## ما الذي يعمل في هذه النسخة؟

- واجهة عربية RTL متجاوبة.
- ثلاثة عوالم تعليمية: 8 و9، العدد 10، العددان 6 و7.
- مشهد Three.js حقيقي بكرات مجسمة يمكن سحبها وإفلاتها داخل السلة.
- عدّ مباشر، تحقق من إنجاز المجموعة، وإعادة المحاولة.
- لوحة أولية لمتابعة التقدم.
- حفظ محلي للتقدم في المتصفح.
- مخطط SQL أولي لجداول Supabase وسياسات RLS.

## التشغيل على الحاسوب

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح العنوان الذي يظهر في الطرفية، غالباً `http://localhost:5173`.

## إنشاء نسخة جاهزة للنشر

```bash
npm run build
```

ينتج مجلد `dist`. يمكن نشره على Vercel أو Netlify أو Cloudflare Pages.

## تفعيل قاعدة البيانات والحسابات الفعلية

1. أنشئ مشروعاً في Supabase.
2. افتح SQL Editor وشغّل محتوى `supabase/schema.sql`.
3. انسخ `.env.example` إلى `.env` وأضف عنوان مشروع Supabase ومفتاح anon.
4. أضف تدفق تسجيل الدخول وإنشاء الحسابات وربط الطالب بمعلمته قبل إتاحة بيانات حقيقية.

**تنبيه مهم:** النسخة الحالية تحفظ التقدم محلياً في المتصفح، ولا تعتبر ذلك نظام حسابات متعدد المستخدمين. لوحة الأستاذة الحالية نموذج أولي محلي. لا تضع مفتاح `service_role` في الواجهة الأمامية. يجب اختبار سياسات RLS وإكمال إجراءات إنشاء الحسابات وربط المعلمة بالتلاميذ قبل نشر بيانات أطفال حقيقية.

## ملاحظات تربوية وتقنية

- الأرقام الظاهرة في العدادات تستخدم الأرقام الأجنبية 0–10.
- أسماء الأعداد والتعليمات بالعربية.
- أنشطة المقارنة والترتيب والكتابة الخطية مدرجة في خطة المحتوى، وتحتاج استكمال واجهاتها التفاعلية قبل اعتبار جميع أهداف الأوراق الثلاث منفذة بالكامل.
- الشخصية الحالية رمز كرتوني مؤقت؛ يمكن استبدالها بصورة مرخصة أو شخصية مصممة خصيصاً.
- الصوت العربي غير مرفق في هذه الحزمة؛ يمكن إضافة ملفات صوت مسجلة أو استخدام خدمة نطق مناسبة بعد اختيار الصوت.

## ملفات مهمة

- `src/data/levels.ts`: محتوى العوالم والأنشطة.
- `src/components/Game3D.tsx`: مشهد العناصر ثلاثية الأبعاد والسحب.
- `src/components/StudentGame.tsx`: منطق اللعب والتقدم.
- `src/App.tsx`: الشاشة الرئيسية ولوحة الأستاذة.
- `supabase/schema.sql`: مخطط قاعدة البيانات وسياسات الوصول.
